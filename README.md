# ¡A PRUEBA!

Spanish listening practice for third-grade students, hosted as a static GitHub Pages site.

## Tests

The sample test and Test 01 are listed in `tests/index.json`. Test 01 includes five M4A recordings and twenty 600×600 PNG answer images. Correct answers are included in the test data for scoring; the separate teacher answer-key file is not included in the public site.

## GitHub Pages

This site is plain HTML, CSS, JavaScript, and static JSON/media. In the repository, open **Settings → Pages**, set **Build and deployment** to **Deploy from a branch**, select `main` and `/(root)`, then save. The site address will be `https://cantatomorrows27.github.io/a-prueba/`.
